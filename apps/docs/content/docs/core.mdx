`@cdr-kit/core` wraps `@piplabs/cdr-sdk` with cdr-kit's deployed addresses, typed errors, and the 2-step
flows as single calls. It is server-safe (no React, no edge runtime).

## Client

```ts
import { createCdrKitClient } from "@cdr-kit/core";

const client = createCdrKitClient({
  apiUrl: process.env.CDR_API_URL!, // Story-API keeper REST base
  publicClient,                     // viem PublicClient
  walletClient,                     // viem WalletClient (for writes)
});
```

## Flows

```ts
import { createVault, writeVaultData, subscribeAndAccess, accessVault } from "@cdr-kit/core";

// Seller — one tx via the CdrKitVault factory (mint NFT → register IP → allocate → configure)
const txHash = await createVault(client, { readConditionAddr, readConfig, licenseTermsId });

// Buyer — pay then read, with progress. The view can't take payment, so this is the 2-step.
const data = await subscribeAndAccess(client, {
  subscriptionCondition, uuid, periods: 1n, maxPricePerPeriod: 10n ** 18n, value: 10n ** 18n,
  onProgress: (step) => console.log(step), // "paying" → "collecting-partials" → "ready"
});

// Already entitled — just read (now with onProgress too)
const bytes = await accessVault(client, { uuid, onProgress: (s) => console.log(s) });
```

<Callout title="uuid comes from the event, not the return">
`createVault` returns a tx hash. The `uuid` is a global counter — read it from the `VaultCreated` /
`VaultAllocated` event in your receipt; it moves between simulate and send.
</Callout>

## File and IPFS path

Payloads over the ~1KB inline cap route off-chain: the body is encrypted to IPFS, the key stays secured
under CDR. `shouldUseFile` tells you which path to take.

```ts
import { uploadFile, downloadFile, createIpfsStorage, shouldUseFile } from "@cdr-kit/core";

const storage = createIpfsStorage({
  addUrl: "https://api.pinata.cloud/pinning/pinFileToIPFS", // or a Kubo RPC /api/v0/add
  gatewayUrl: "https://gateway.pinata.cloud",
  headers: { Authorization: `Bearer ${PINATA_JWT}` },
});

if (shouldUseFile(content)) {
  const { uuid, cid } = await uploadFile(client, { content, storage });
  const { content: bytes } = await downloadFile(client, { uuid, storage });
}
```

`createMemoryStorage()` is a zero-network, content-addressed provider for tests and CI.

## Errors & retries

Every failure is a typed `CdrError` with a `code`, `recoverable`, and `suggestedAction` — branch on it
in UIs, read `suggestedAction` in agents. Wrap transient keeper/storage calls in `withRetry` (exponential
backoff + jitter — it never retries on-chain txs).

```ts
import { CdrError, withRetry } from "@cdr-kit/core";

try {
  await withRetry(() => accessVault(client, { uuid }));
} catch (e) {
  if (CdrError.is(e, "CONDITION_NOT_MET")) promptToSubscribe();
}
```

## WASM

`initWasm()` (via `ensureWasm()`) must run before any encrypt/decrypt — the SDK flows call it lazily, and
`<CdrProvider>` handles it for you.
