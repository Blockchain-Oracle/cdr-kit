**cdr-kit** is the wagmi/Stripe layer for Story Protocol's Confidential Data Rails — a standard library of
audited condition contracts, a typed TypeScript SDK, a React layer, and an autonomous agent kit, so you can
ship private, paid, license-gated data on Story without hand-rolling the protocol.

CDR's encryption is commodity (Lit/TACo do it too). cdr-kit's edge is the **Story IP coupling** — license-tier
gating + royalty rails — made usable, plus the DX: typed errors, first-class read-latency status, mock mode,
and a one-tx vault factory.

## The constraints, up front

- **~7-min read latency.** A CDR read collects validator partial decryptions; it is async. Every read path in
  cdr-kit exposes determinate status (`paying → collecting-partials → ready`) — never a bare spinner.
- **2-step pattern.** A condition is a pure `view` and can't take payment — you pay/subscribe (a tx), then the
  `view` reads the result. The SDK's `subscribeAndAccess` does both.
- **~1KB inline cap.** Larger payloads route to the [file/IPFS path](/docs/core#file-and-ipfs-path).
- **Testnet only.** Deployed on Story Aeneid (chain 1315). No mainnet.
