## createVault signature

<CodePanel title="CdrKitVault.sol" code={`function createVault(
  address readConditionAddr,
  bytes calldata readConfig,
  address[] calldata childConditions,
  bytes[] calldata childConfigs,

## Events

<p>Emits <code>VaultCreated(tokenId, uuid, ipId, creator, licenseTermsId)</code> — read the <code>uuid</code> from the tx receipt; never predict it (global counter).</p>

## Gas note

<p>The factory nests a CDR precompile call (<code>allocate</code>) whose gas <code>eth_estimateGas</code> underestimates. Always set an explicit gas limit (<code>3_000_000</code> is the SDK default).</p>
