## Config shape

<ul>
  <li><code>mode: uint8</code> — 0 = AND, 1 = OR.</li>
  <li><code>children: address[]</code> — child condition addresses (1–8).</li>
</ul>

## accessAuxData

<p>ABI-encoded <code>bytes[]</code> of per-child aux, aligned to the configured children order.</p>
