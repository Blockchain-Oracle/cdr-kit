## Install

<CodePanel title="terminal" language="bash" code={`$ npm install -g @cdr-kit/cli
$ cdr --help`} />

## First run

<CodePanel title="terminal" language="bash" code={`$ cdr wallet
# first run prints a banner with the auto-generated address + faucet URL → stderr
# subsequent runs return the wallet state as JSON / pretty-printed object`} />

<p>The wallet is generated by viem's <code>generatePrivateKey()</code>, stored at <code>~/.config/cdr-kit/wallet.json</code> (resolved cross-platform via <code>env-paths</code>), and written with <code>chmod 600</code>. Override anytime with <code>CDR_PRIVATE_KEY=0x...</code>.</p>

## Use as MCP server

<p><code>cdr mcp</code> is the same stdio server <code>@cdr-kit/mcp</code> ships. Either binary works for MCP host configs — most prefer <code>npx @cdr-kit/mcp</code> for zero install footprint.</p>

<CodePanel title="terminal" language="bash" code={`$ claude mcp add cdr-kit npx @cdr-kit/mcp`} />
