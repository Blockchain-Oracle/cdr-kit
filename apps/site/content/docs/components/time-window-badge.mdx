## Block-based windows

<p>For windows configured with <code>blockBased: true</code>, the client-side <code>opensInMs</code>/<code>closesInMs</code> return <code>0</code> — block.number can't be ticked client-side cheaply. Render the raw block bounds from the state object instead.</p>
